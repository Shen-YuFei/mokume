# Python API (package)

The pure-Python `mokume` package (`pip install mokume`) exposes a class-based API
for quantification and differential expression. The reference below is rendered
directly from the package source, so it always matches the installed version
rather than a hand-written copy.

For the Rust-accelerated wheel's thin in-process API, see
[Python API (wheel)](python-api.md).
